# Virya Coaching

Landningssida för Virya Coaching – nervsystemsbaserat hållbart ledarskap.

**Live:** https://viryacoaching.github.io/erbjudande/

## Se sidan lokalt

Öppna `index.html` i en webbläsare, eller kör en lokal server:

```bash
python3 -m http.server 8000
```

Gå sedan till http://localhost:8000

## Publicering

Sidan publiceras med GitHub Pages från `main`-grenen (rot-mappen).

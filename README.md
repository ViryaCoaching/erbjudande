# Hur Claude Code fungerar

En enkel ensidig hemsida som förklarar vad Claude Code är och hur det fungerar.

## Se sidan lokalt

Öppna `index.html` i en webbläsare, eller kör en lokal server:

```bash
python3 -m http.server 8000
```

Gå sedan till http://localhost:8000

## Publicering

Sidan publiceras med GitHub Pages från `main`-grenen (rot-mappen).
